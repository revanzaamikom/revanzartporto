## Perbaikan diterapkan (semua scoped `≤900px`, tidak menyentuh desktop)

**1. Card proyek terpotong + teks mepet** (`webportofolio.astro` @media max-width:900px)
```css
.wp-slide { max-height: none; overflow: visible; padding: 22px 20px 24px; }
.wp-slide__body { overflow: visible; padding-right: 0; }
.wp-slide__shot { margin: -22px -20px 18px; aspect-ratio: 16/10; }
.wp-slide__shot img { position: static; height: auto; }
```
Card memanjang penuh sesuai isi, teks tak lagi terklip, padding berlaku normal.

**2. Jarak judul → card stack** (akar "kurang padat")
```css
.wp-stack-stage { position: static; height: auto; min-height: 0; display: block; padding: 0; }
.wp-stack-card + .wp-stack-card { margin-top: 16px; }
.wp-head { margin-bottom: 22px; }
```
→ celah 153px turun jadi **58px** (390/360/430), 83px di 320 (judul wrap 2 baris — wajar).

**3. Antar section mepet** → padding section **simetris**:
```css
.wp-section { padding-top: clamp(64px,9vw,96px); padding-bottom: clamp(64px,9vw,96px); }
.wp-track-section { padding: clamp(64px,9vw,96px) 0; }
```
→ terukur `64/64` di semua viewport mobile; garis pemisah section tidak lagi nempel konten.

**4. Scroll effect ringan mobile** (bukan pin/sticky berat)
- `initMobileCardReveal()`: reveal stagger fade-up untuk `.wp-slide` & `.wp-stack-card`, **hanya saat `stacked`** (≤900px) — desktop tidak terpengaruh.
- Bug dicegah: `render()` saat `stacked` dulu me-reset inline style kartu (`transform=''; opacity=''`) yang membunuh reveal → kini tidak menyentuh kartu di mobile.
- Reveal `data-fade`/`data-split`, counter `data-value`, progress bar, marquee tetap aktif.

**5. iOS zoom + navbar legibilitas**
```css
.wp-field__input { font-size: 1rem; }           /* 15.2px -> 16px */
@media (max-width:640px){ .wp-field__input { font-size:16px; } }
```
`Navbar.astro` (varian web): font ≤360/≤330px dinaikkan dari `0.58rem` (~9.3px) → `0.68rem` (~10.9px), padding dirapatkan (bukan teks dikecilkan sampai tak terbaca).

## Lanjutan: judul section kepotong + jarak antar-section (2026-10-12)

**Keluhan owner:** "antar semua section itu title section kepotong terlalu mepet dengan section atasnya" → "title section mepet banget, kepotong dikit bagian atas".

**Diagnosis (CDP 390px):**
- `gapFromPrevSec: 0` (semua section) + judul `64px` dari section atas → judul nempel section sebelumnya.
- Judul ter-clip: `[data-split]` + `.wp-word { overflow:hidden }` (mask reveal). Terukur inner span `innerTransform: translateY(42.2px)` di dalam mask tinggi 38px → pangkal kata terpotong saat animasi belum tuntas.

**Fix:**
```css
/* mask diberi headroom supaya glyph tidak terpangkas, reveal tetap jalan */
.wp-word { overflow: hidden; padding-bottom: 0.16em; margin-bottom: -0.16em; }
[data-split] { overflow: visible; }
```
```css
@media (max-width: 900px) {
  .wp-section, .wp-track-section { padding-top: clamp(88px,12vw,104px); padding-bottom: clamp(64px,9vw,88px); }
}
```

**Verifikasi sesudah (terukur):**
- 390/360: `padTop 88px`, `titleFromSecTop 88px` (dulu 64), `h2Overflow: visible`, word mask 42px vs glyph 38px, `innerTopInsideMask ≥0` (tidak ter-clip saat reveal).
- **Desktop 1440 TIDAK regresi:** track-stage sticky 900, stack-stage sticky grid 900, slide `overflow:hidden max-height:680 display:grid`, layananPad 108/80, pin height 3915, navbar 6 link, no horizontal overflow.
- `npm run build` ✓ Complete.
