## Temuan (order: user impact)

### [1] HIGH — Link email di form fallback punya tap target terlalu kecil (16px)
- **Bukti terukur:** `.wp-form__fallback a` (`importantrevanza@gmail.com`) = **185 x 16 px** di
  320/360/390/430px. Tinggi 16px jauh di bawah minimum **44px** (R-03, UX priority 2 "Touch & Interaction",
  design-taste §4.5). Berada tepat di bawah tombol "Email" → risiko salah tekan (user menekan tombol
  Email, bukan link teks). Dikonfirmasi vision: "area tap-nya KURANG / mepet".
- **Rule:** R-03 (tap target 44px), R-26 (elemen interaktif harus nyaman dioperasikan).
- **Perbaikan terkecil:** beri link email `display:inline-flex; align-items:center; min-height:44px;
  padding-block: 12px;` (atau jadikan baris penuh dengan target 44px). Visual teks tidak berubah drastis.

### [2] LOW — Marquee: elemen `wp-marquee__item` terbaca "keluar viewport" oleh pengukuran
- **Bukti:** di semua viewport, `.wp-marquee__track` membentang -432..2277px.
- **Klasifikasi: BUKAN DEFECT.** Parent `.wp-marquee { overflow: hidden }` mencegah scroll horizontal
  (terbukti: `document.documentElement.scrollWidth == viewport`). Ini animasi marquee yg memang overflow
  di dalam container terpotong. Tidak ada perbaikan diperlukan. Dicatat agar tidak dianggap bug lagi.

### [3] INFO — Catatan pilihan desain (bukan defect)
- Grid teknologi & kartu paket = 1 kolom di mobile, faktur "Tentang" = 1 kolom. Ini konsekuensi wajar
  layout mobile (bukan salah). Tidak diubah tanpa permintaan owner.
- Padding-top section 104px terasa lega di mobile; itu **permintaan owner** ("sedang"), dipertahankan.
- Beberapa klaim vision ("gambar proyek terpotong", "kartu 06 terpotong") = **false positive**:
  pengukuran DOM membuktikan frame 340x213 (ratio 1.60 = persis gambar, cover = utuh) dan 6 kartu
  Proses tampil penuh. Tidak ditindaklanjuti.
